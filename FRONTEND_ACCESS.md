## 🎯 What to Try

### 1️⃣ **Mechanic Dashboard** (Recommended First!)
- Login as Mechanic
- Select a vehicle from the dropdown
- Click **"Run Diagnosis"** button
- Wait 3-6 seconds for AI processing
- Click **"View Details"** on any diagnosis
- See ML predictions, SHAP explanations, repair guides!

### 2️⃣ **Admin Dashboard**
- Login as Admin
- Switch between tabs: Overview, Users, Showrooms, Analytics
- View system-wide metrics and AI performance
- See user management and showroom cards

### 3️⃣ **Showroom Dashboard**
- Login as Manager
- View showroom statistics and revenue
- Browse vehicles, mechanics, and diagnoses
- See recent activity and performance

### 4️⃣ **Owner Dashboard**
- Login as Owner
- View vehicle health scores (0-100)
- Check service history
- Read diagnosis reports
